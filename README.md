# IPO Pulse

A mobile-first Progressive Web App (PWA) for the InvestorGain IPO dashboard.

## Deploy
Upload these files to a GitHub repository and enable GitHub Pages. The site must be served over HTTPS for normal PWA installation.

After deployment, open the HTTPS site in Chrome on Android and choose **Install app** / **Add to home screen**.

## Data
The dashboard reads InvestorGain's public pages through browser-compatible fetch proxies. GMP is unofficial/indicative data.
